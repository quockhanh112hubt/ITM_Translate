Smart translation software with AI API

Quickly translate text with hotkeys, supporting natural language translation.

✨ Key Features

  • 🔤Quick Translation: Select text and press hotkey for instant translation
  • 🔊Text-to-Speech: Read the translation aloud
  • 🎯Subtitle Sync: Highlight words as they are read
  • 🤖Multi-AI: Supports Gemini, ChatGPT, Claude, DeepSeek, and Google Translate with automatic failover
  • 🌍Multilingual: Automatically detects and translates to multiple languages
  • ⚡Hotkeys: Customizable shortcuts (suggested: Ctrl+Q, Ctrl+D or Ctrl+1, Ctrl+2)

🚀 Download & Installation

Download the Windows installer (.exe) from GitHub Releases

After installation, launch the program and follow the instructions in the Advanced Tab > User Guide

🖼️ Screenshots / Demo

🚦 API Key Setup

  1. Open the program → "API Key Management" Tab
  2. Add API keys from one of the providers:
    • Gemini (recommended): Google AI Studio
    • ChatGPT: OpenAI API
    • Claude: Anthropic Console
    • DeepSeek: DeepSeek Platform

Note: API keys are stored locally on your machine. If you lock/revoke the key, update it in the app to avoid errors.

🧭 How to Use

  1. Popup Translation: Select text → Press Ctrl+Q
  2. Replace Translation: Select text → Press Ctrl+D
  3. Text-to-Speech: To hear the translation, click the 🔊 button in the popup
  4. Customization: "Settings" Tab to change hotkeys and languages

❓ Support & FAQ

  • Hotkey not working: Try running the app as Administrator or check for conflicts with other hotkey software
  • API key error: Check the key in the "API Key Management" Tab
  • No voice: Install Windows Speech Platform / check voice packs

Q: Can it be used for free? A: Yes, but requires API keys from providers (some have free tiers)

Q: Supports offline translation? A: No, requires internet to connect to AI providers

Q: Text length limit? A: Each provider has different limits (~4000-8000 characters)

Q: Mobile app? A: Not yet, currently only supports Windows desktop
