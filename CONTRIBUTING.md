Thank you for your interest in contributing to ITM Translate! Please follow these guidelines to make collaboration smooth.

1. Filing issues
   - Search existing issues before filing.
   - Provide steps to reproduce, logs, screenshots and environment (Windows version, Python version if running from source).

2. Pull requests
   - Fork the repo, create a feature branch, and open a PR against `main`.
   - Keep changes small and focused. Add tests where possible.
   - Use clear commit messages and reference related issues.

3. Code style
   - Python: follow PEP8. Use black/flake8 where convenient.

4. Security
   - Do NOT commit secrets or API keys. Use `api_keys.json.example` as template.

Thanks — maintainers will review PRs as time allows.
